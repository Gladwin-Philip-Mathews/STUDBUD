# Documentation

- `m3-traceability.md`: each M3 design item (stores, processes, classes, operations) and the file that implements it.
- `requirements-coverage.md`: each requirement ID with its code and tests.
- `test-report.md`: final test results and what is not covered.
- `deferred-requirements.md`: what was not built or has a stated limit.
- `api.md`: the JSON API.
- `feature-guide.md`: how to add a feature.
- `REVIEW.md`: the 20 November review against the SRS and the M3 design, with what was fixed and what stays open.
- `diagram-conformance.md`: the built system checked against the M1 and M3 diagrams, with the differences that belong in the M3 change record.
